🧭 Code-Compass — Your Personal Coding Learning Tracker

🚀 Track Your Progress. Master Your Code.

Code-Compass is a personal coding learning tracker designed to help students build consistent coding habits, monitor their programming skills, set daily coding goals, and visualize their learning journey.

💡 About the Project

Learning to code requires consistency and practice. Code-Compass aims to make that journey easier by providing a single place to record coding activities, track progress, and stay motivated.

This project is being developed as part of my journey as a B.Tech Information Technology student.

✨ Key Features

- 📊 Progress Tracking — Monitor your coding journey.
- 💻 Language Tracker — Keep track of the programming languages you are learning.
- 🎯 Daily Goals — Set and manage daily coding targets.
- 🔥 Learning Streaks — Stay consistent with your practice.
- 📝 Coding Journal — Record what you learn every day.
- 📈 Progress Visualization — View your learning progress.
- 🏆 Achievements — Celebrate your coding milestones.

🛠️ Technologies Used

The planned technologies for this project are:

- HTML
- CSS
- JavaScript
- Chart.js

🎯 Project Objectives

- Encourage consistent coding practice.
- Help students organize their programming goals.
- Track learning progress in one place.
- Make learning programming more engaging.

🚀 Future Enhancements

- Personalized coding roadmaps.
